# Goddessverse published sites

This repository contains publication output from private Goddessverse Lab.

- [TipsyPrompt](https://goddessverse.github.io/tipsyprompt/): the existing static site and original author credits are preserved.
- Edit the experiment in [Lab](https://github.com/Goddessverse/lab/tree/main/experiments/tipsyprompt); its publishing workflow updates this copy.
- `tipsyprompt/lab-source.json` records the source revision and public-file hashes.

The original project is derived from [SpicyChatRae/tipsy](https://github.com/SpicyChatRae/tipsy). This is publication infrastructure, not a replacement development repository.
