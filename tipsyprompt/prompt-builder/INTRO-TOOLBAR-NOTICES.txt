Auri Formatting Toolbar assets adapted for Tipsy Prompt Builder
==============================================================

This local bundle reuses the existing Auri toolbar source and authored catalogs from
experiments/obsidian-plugin/src/plugins/auri-toolbar. No Obsidian runtime, personal
settings, saved favorites, recent items or credentials are included.

The Unicode style mappings and transformation functions are copied from main.js,
with a browser-global wrapper and an argument-order adapter. References retained
from the original source: Unicode Mathematical Alphanumeric Symbols,
https://www.unicode.org/charts/nameslist/n_1D400.html; screenshot-selected mappings
from discord-fonts.com; additional alphabet samples from Glyphy and Fontb.

Catalog sources
---------------
- Unicode emoji data: Unicode 17.0, 3,944 fully-qualified sequences.
  https://www.unicode.org/emoji/charts-17.0/emoji-list.html
  https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt
- Symbol catalog: https://www.fontb.com/cool-symbols, retrieved 2026-09-28.
  Names and categories are retained from the source catalog. No separate upstream
  catalog license was included in the existing local source. Attribution does not
  imply an additional license grant.
- Kaomoji catalog: https://coddy.tech/tools/kaomoji, retrieved 2026-09-28, with
  legacy entries and user-authored additions preserved. The original project
  documentation records that no explicit upstream catalog license was identified.
  Attribution does not imply a license grant. No site application code or articles
  are included.
- user-symbols.json: shipped authored character catalog, source labeled
  "User supplied characters, 2026-09-28"; not runtime settings.
- combo-data.json: shipped authored combinations/templates, source labeled
  "User supplied combos, 2026-09-28".
- Enclosed alphanumeric and control-picture entries: local Unicode-name catalogs.

The grouped category catalog preserves the existing local picker's deduplication
and ownership rules, including emoji/text presentation cleanup.
